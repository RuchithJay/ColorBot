# 🎨 Discord Color Palette Bot
A bot that extracts color schemes from images and provides detailed color analysis
### ✨ Features
* Extract color palettes from any image (auto-detects or via /palette command)
* Get HEX, RGB, HSL, and CMYK values with /colorinfo
* Generate color harmonies (complementary, triadic, etc.)
* Visual color swatches with customizable sizes
* Works with attachments, URLs, or color codes

### 📜 Commands
`/palette`     - Extract colors from an image  
`/colorinfo`    - Get details about any color  
`/compare`      - Compare two colors side-by-side  
`/suggest`     - Generate color harmonies
